## 六、架构红线（后续必须遵守）

1. **零 agent、零 skill、零编排（产品运行时）**——skill/agent 只是开发期工具，不进产品架构。
2. **内容管线是唯一真身**：`intent→evidence→plan→narrative→polish→gate`，其余都是它的消费者。
3. **书籍化 = 渲染器模式**：同一份「溯源叙事」→ `render_web()`（已有）/ `render_book()`（新增）/ `render_…()`（未来），是纯函数不是层。
4. **溯源是立身之本**：绝不叠加「全书 LLM 重写」；排版零 token；序/引子/桥必须过 Gate + 溯源。
5. **命题策划已拆 propose/critique**：不要再合并回单调用，也不要引入多 agent 编排。
