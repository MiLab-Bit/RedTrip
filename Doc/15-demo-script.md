# 15 · 90 秒演示脚本（竞赛现场 · 与当前 FSM 对齐）

> 目标：评委听完能记住一句话——**目录给条目，我们给关系**。  
> 真实主路径：**Brief → Loading/流式 → 序章 → 章节阅读 →（可选）看全图 → 收尾**。

---

## 0. 开场前（T-2 min）

| 项 | 操作 |
|---|---|
| API | `http://127.0.0.1:8799/v1/health` 见 `ok:true`、`whitelist:true` |
| Web | `pnpm --filter @redtrip/web dev` |
| 预热 | 用默认槽位先策展一次，吃到缓存（冷启动勿赌） |
| 备援 | 录屏：`Videos/RedTrip/demo-90s-primary.mp4` |

口播一句（可选）：「演示环境；主证据来自上海图书馆开放数据，OSM/地图仅作步行示意。」

---

## 1. 90 秒口播节奏

| 秒 | 画面 | 你说什么 | 手势 |
|---|---|---|---|
| 0–8 | Brief 出题页，品牌 **红鸢 RedTrip** | 「别人给你一条红色线路；我们用上图馆藏，为你策一场城市展览。」 | 停在出题页 |
| 8–18 | 槽位：2人 / 90分钟 / 轻社交 / 武康路 | 「出题只要四件事：和谁、多久、什么调性、从哪一带走。」 | 点「开始策展」 |
| 18–32 | Loading → 流式序章 | 「先取证，后叙事。没有出处的句子不会假装有出处。」 | 等序章出现 |
| 32–55 | 进入第 1 章（巴金故居） | 「同一栋楼：建筑层、人物层、事件层——关系，不是目录。」 | 指右侧关系图 / 时间轴 |
| 55–72 | 出处抽屉 + 避坑「未收录」+ 馆藏 URI | 「每句能点开看出处；开放时间不确定就写未收录，不猜。」 | 点出处 chip；指避坑 |
| 72–85 | 「看全图」3 秒或下一章衔接句 | 「站与站之间用史实衔接，不用『步行五分钟』当理由。」 | 看 transition |
| 85–90 | 主题句 / 收尾卡 | 「目录给条目，我们给关系。」 | 停 1 秒结束 |

## 2. 评委追问（各 15 秒）

| 问 | 答 |
|---|---|
| 会不会瞎编？ | Gate + 红队；未取证年份会被拒；Gate 失败返回 `degraded`，不伪装成功。 |
| 28 家数据源？ | **已注册 28；已接通 live 2（上图 + 搜韵）**；其余待授权落盘。诚实比注水重要。 |
| 没坐标怎么办？ | 白名单核录 + precision 诚实；示意坐标不标 exact。 |
| 游客要登录吗？ | 不需要。登录/自带模型密钥是增强项，不挡主路径。 |

---

## 3. 演示禁语

- 「一键生成」「省时省事」  
- 「28 家全接通」「全市建筑库」  
- 「我们深度更高」（改讲产能与可核验关系）  
- 口号体 / 表态动员  

---

## 4. 失败剧本（30 秒）

网断 / Key 失效 → **先播录屏**，再口头解释管线与 Gate。  
切勿现场临时改代码。
