# 15 · 90 秒演示脚本（竞赛现场）

> 目标：评委听完能记住一句话——**目录给条目，我们给关系**。

---

## 0. 开场前（T-2 min）

| 项 | 操作 |
|---|---|
| API | `dev-api.cmd` → `http://127.0.0.1:8787/v1/health` 见 `ok:true`、`whitelist:true` |
| Web | `pnpm dev` → `http://127.0.0.1:5173/` |
| 备援 | 若 indexed 抖，设 `REDTRIP_MODE=snapshot` 重启 API；点通仍用 fixture |
| 录屏备份 | 见下文「备份录屏路径」 |

口播一句（可选）：「这是竞赛演示环境，数据来自上海图书馆开放接口 + 本地 R-20 白名单。」

---

## 1. 90 秒口播节奏

| 秒 | 画面 | 你说什么 | 手势 |
|---|---|---|---|
| 0–8 | Brief 出题页，品牌 **RedTrip** 可见 | 「别人给你一条红色线路；我们用上图馆藏，为你策一场城市展览。」 | 停在出题页，勿急点 |
| 8–20 | 槽位：人群成人 / 场景武康 / 90 分钟 / 轻社交 | 「出题只要四件事：和谁、多久、什么调性、从哪一带走。」 | 点「开始策展」 |
| 20–35 | Loading → 地图 | 「先取证，后叙事。没有出处的句子不会出现在路线里。」 | 等地图出现 |
| 35–55 | 点开第 1 站故事卡 | 「同一栋楼：建筑层、事件层、人物关系层——关系，不是目录。」 | 点开「出处」抽屉 |
| 55–70 | 出处抽屉 + 避坑四字段 | 「每句能点开看出处；开放时间不确定就写未收录，不猜。」 | 指 pitfalls |
| 70–85 | 回地图 / 下一站衔接句 | 「站与站之间用史实衔接，不用『步行五分钟』当理由。」 | 点下一站看 transition |
| 85–90 | Done 或主题句 | 「目录给条目，我们给关系。」 | 停 1 秒结束 |

## 2. 评委可能追问（各 15 秒）

| 问 | 答 |
|---|---|
| 会不会瞎编？ | Gate + 红队 12 条；无 `source.dataset`/`record_id` 的事实句不放行。 |
| 没坐标怎么办？ | v1 走 R-20 白名单核录；NG-10 渲染只读 lat/lng，不按来源分叉。 |
| 为什么只有上海？ | 竞赛 v1 收敛梧桐区 + 一大周边 30 点；引擎可换内容池。 |
| 上游挂了？ | `snapshot` fixture 仍可完整点通演示路径。 |

## 3. 备份录屏路径

现场网断 / Key 失效时，**先播录屏，再口头解释**。

建议落盘（任选其一，演示前拷到 U 盘）：

```
%USERPROFILE%\Videos\RedTrip\
  demo-90s-primary.mp4      ← 主片（indexed 武康线，含出处抽屉）
  demo-90s-snapshot.mp4     ← 备片（REDTRIP_MODE=snapshot）
  stills\                   ← 关键帧：brief / map / story+source / done
```

录制清单（主片）：

1. Brief → 提交默认槽位  
2. 地图出现 ≥6 站  
3. 打开 1 站故事卡 + 出处  
4. 看避坑「未收录」  
5. 下一站 + Done  

工具：Windows「Xbox Game Bar」`Win+G`，或 OBS 本地文件。  
**禁止**把 `.env` / API Key 录进画面。

## 5. 失败剧本（30 秒）

1. 画面进 **未能放行 / 降级** → 念错误原因一行  
2. 「切 snapshot」→ 改 `.env` `REDTRIP_MODE=snapshot` 重启 API，刷新页面再点一次  
3. 仍失败 → 播 `demo-90s-snapshot.mp4`，指着 `content/fixtures/demo-route.json` 说明契约未变
