# ADR-002 · 坐标源可替换（NG-10）

- 状态：已采纳  
- 日期：2026-08-06  

## 背景

v1 用人工核录示意图坐标，以摆脱外部地理审批；S1 可能回填上游真坐标。若两套数据结构分叉，S1 会变成重做。

## 决策

`GeoPoint` 字段固定：`lat/lng/coord_source/precision`。  
渲染与交互只读坐标与精度，**不**按来源分叉逻辑。回填 = 改值 + 翻标记。

## 后果

- 正向：S1 是数据替换不是重写  
- 约束：禁止 `schematic_lat` 等平行字段；示意图也必须走同一渲染器
