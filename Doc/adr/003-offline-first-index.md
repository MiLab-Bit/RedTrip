# ADR-003 · 离线索引优先

- 状态：已采纳  
- 日期：2026-08-06  

## 背景

1. 本机代理可导致上图 TLS 失败（非缺 Key）。  
2. 中文关键词可能在 MCP 桥接层编码崩溃。  
3. 竞赛演示需要可重复、可脱网演。

## 决策

- 离线灌库 + 本地中文倒排  
- 在线主链路仅用 `buri` 等 ASCII 参数访问上游（或直接读快照）  
- 允许演示使用「可溯源快照」；对外可去掉「实时」二字，不削弱 G1

## 后果

- 正向：主路径稳定；避开编码坑；时延可控  
- 代价：需维护灌库脚本与索引版本；内容新鲜度依赖更新节奏
