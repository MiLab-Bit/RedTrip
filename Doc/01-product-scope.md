# 01 · 产品范围（工程裁剪版）

> 完整需求见 PRD v2.0。本文只保留工程开工所需的边界。

---

## 1. v1 一句话

以上图跨库开放数据为基底，在**上海 · 梧桐区 + 一大周边 · 30 点位白名单**内，为用户现产一条 ≤120 分钟、事实可溯的城市记忆路线，并用 2.5D 示意图呈现。

---

## 2. 主流程（五步）

```
① 出题（≤30s，最多 1 问）
② 策展（取证 → 跨库缝合 → 选点排序 → 叙事 + 策展说明）
③ 2.5D 城市记忆地图（序号 / 连线 / 距离 / 耗时）
④ 漫步（点位卡片，可断可续）
⑤ 收尾（纪念卡 / 素材导出 · P1）
```

---

## 3. P0 必交付（工程编号）

| ID | 需求 | 工程含义 |
|---|---|---|
| R-01 | 6 槽位出题 | 人群 · 场景 · 时长 · 调性 · 交付形态 · 同行结构 |
| R-02 | 取证与出处 | 事实句 100% 带数据集 + 记录标识 |
| R-03 | 跨库缝合 | 保底「建筑 + 事件」两重；目标三重（S0-4 实测） |
| R-04 | 路线引擎 | 5–8 点、≤120min、步行合理、成功率 ≥95% |
| R-05 | 2.5D 示意图 | 可降为静态图；必须满足 NG-10 |
| R-06 | 故事卡 | 第二人称 + 年龄对照；每路线 ≥3 条非通识细节 |
| R-07 | 质检门禁 | 阻断项 FAIL → 不出稿 |
| R-19 | 策展说明 | 开篇策展词 + **史实衔接**（禁「步行 5 分钟」当理由） |
| R-20 | 白名单核录 | 30 点位坐标 / 开放 / 可入内 / 预约 / 机位 |

**绝不砍**：R-02 / R-06 / R-19。  
**可裁剪顺序**：R-10 → R-09 → R-05 降静态图。

---

## 4. Non-goals（v1 明确不做）

- 真人领队、组团、售票、导航 App
- 软件订阅、支付闭环
- AR / 剧本杀 / NPC / UGC 社区
- 全国点位、照片级实景三维
- 无出处历史事实生成

---

## 5. 竞赛口径（全员）

1. 禁写「我们深度更高」——对外：同属策展级，差异在产能。
2. 主威胁叙事：沪小游是广度入口；我们做关系层。
3. 核心演示句：「目录再多也生成不出『一栋楼的多重人生』。」
4. U4：若实测仅两重 → 对外改称「一栋楼的两重人生」，不硬撑四重。
