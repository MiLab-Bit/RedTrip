# 红鸢 RedTrip · 冲奖作战手册（质量优先）

> 主题对齐：第十一届上图开放数据竞赛「典籍新生，数据里的文脉风华」  
> 赛道：应用开发及智能体  
> 官方评奖五维：**创新性 · 可行性 · 技术含量 · 交互体验 · 开放数据利用程度**  
> 原则：先质量、后部署；少承诺、多核验。

---

## 0. 评委眼里你在比什么

| 官方维度 | 红鸢该怎么赢 | 现在最危险的扣分点 |
|---|---|---|
| **开放数据利用程度** | 演示线每站 buri/URI 可点开；跨库 join 看得见 | 吹「28 家」但 ready 只有 2；180 点仅 24 有 buri |

金句只留一句：**目录给条目，我们给关系。**

## 1. 产品定位（答辩口径，锁死）

**一句话**  
别人给你一条红色线路；我们用上海图书馆的真实馆藏，为你策一场只属于你的城市展览。

**允许说**
- 取证先于叙事；无出处不出稿 / 降级诚实标注  
- 建筑 × 事件 × 人物 的关系编织（实测几重就讲几重）  
- 上图开放数据是主证据源；OSM/高德仅作地理可达与示意补充  
- 已接通 live：上图聚合入口 + 搜韵；其余机构数据为注册待授权

**禁止说**
- 「我们深度更高」「28 家全接通」「全市建筑库」  
- 「一键生成」「每站必有 8000–10000 字馆藏原文」  
- 「句句 100% 馆藏」——除非句级 provenance 已接通且可抽查

## 2. 质量优化优先级（部署之前只做这些）

### P0 · 信任底座（不做就别答辩）

1. **红队变绿 + CI**  
   - 同步 fixture 与禁词（第二人称策略二选一：卡片允许 / 长散文禁止）  
   - `pytest` + `run_redteam` 进 CI  
   - 验收：本地一键全绿，截图进答辩材料

2. **API 状态诚实**  
   - Gate 失败 / 模板回退 → `status=degraded`，`gate.passed=false`  
   - 前端必须可见降级提示  
   - 验收：人为注入禁词后，响应不是假成功

3. **开放数据利用「看得见」**  
   - 锁定 1 条竞赛演示线（建议：一大周边 6 站）  
   - 每站至少 1 个可点击的上图 URI / buri  
   - 故事卡 ≥3 条「非百度通识」细节，且出处可展开  
   - 验收：评委离线也能顺着 URI 核到馆藏字段

4. **演示路径与脚本同版本**  
   - 统一为：Brief → 流式序章 → 第 1 章（关系+出处）→ 看全图 3 秒 → 金句  
   - 预热缓存；准备 90 秒录屏备援  
   - StopPanel 渲染 pitfalls（「未收录」高亮）

### P1 · 差异化拉满（显著加分）

1. 挂载「多层身份」可视（时间轴或 building/event/person 分层），服务「一栋楼的多重人生」  
2. 接通 `sentence_provenance`，句末角标可点（这是对图书情报评委最甜的点）  
3. Brief 竞赛模式：默认只暴露 和谁 / 多久 / 调性 / 从哪走；多城折叠  
4. 健康面板口径：`providers_ingested=2` 对外解释清楚，禁止注水

### P2 · 明确后置（现在做是分心）

- 新域名、完整上线联调、支付/账号体系打磨  
- 14 城铺开、展讯实时、GraphRAG、MDX 按钮、机位长图工厂  

这些不决定九十月评审能不能赢。

## 3. 「典籍新生」主题怎么贴死

竞赛要的是：**馆藏文献 → 可感知的城市记忆**，不是旅游 App。

建议在作品说明与开场 20 秒内完成三次映射：

| 竞赛话语 | 红鸢对应物 |
|---|---|
| 典籍 / 馆藏数据 | 上图 architecture / red_event 等 URI 取证 |
| 新生 / 活化 | 出题→策展→可走的展览书 |
| 文脉风华 | 海派书页 + 关系叙事（非口号） |
| 红色文化表达（赛道方向） | 一大周边线：会议—弄堂—马路—日常 |
| 智能体 | 可解释管线 + Gate + 反方策展人 |

---

## 4. 建议的作品材料包

1. **可交互微站**（现有即可，先别换域名）  
2. **90 秒无声/有口播演示视频**（缓存热路径）  
3. **1 页技术说明**：管线示意图 + Gate 规则表 + 红队截图  
4. **1 条完整 envelope JSON**（含 sources/buri）作为附件  
5. **诚实的数据利用说明**：用了哪些官方数据集、哪些是辅助地理数据  

人气奖可并行拉票，但一等奖靠评委五维，不靠票。

## 6. 最终判断

红鸢已经具备冲一等奖的骨架：**开放数据 + 智能体策展 + 防幻觉工程 + 可走可读交付**。  
赢的关键不是再做一个更大的平台，而是让评委在 90 秒内**核验到**：  
这不是生成式旅游文案，而是**基于上图开放数据的、可追溯的城市记忆策展智能体**。

先把信任做实，再谈新网址与完整上线。
