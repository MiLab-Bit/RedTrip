## 🔴 P0-1 `intent.py` — city 路径穿越白名单

**文件：** `packages/curator/redtrip_curator/intent.py`  
（防御纵深建议同步：`packages/curator/redtrip_curator/cities.py` 的 `get_city`）

**当前现状：**  
`parse_intent` 把 `slots["city"]` 原样写入 `Intent.city`。下游 `rag.py` / `evidence.py` 用  
`curated / f"{city}-landmarks.json"` 拼路径。`get_city()` 虽对「未知 key」回退上海，但 **intent 未调用它**，恶意字符串会进路径。

**应该怎么改：**

1. `cities.get_city`：先用 `^[a-z]{2,32}$` 校验；不通过或未注册 → `shanghai`。  
2. `parse_intent`：`city = get_city(raw).key`（只存注册表 key）。  
3. 加测试 `tests/test_intent_city_safe.py`，覆盖：
   - `"../../../etc/passwd"` → `shanghai`
   - `"shanghai; rm -rf /"` → `shanghai`
   - `"suzhou\n\necho pwn"` → `shanghai`
   - `"suzhou"` / `"hangzhou"` → 原样

**为什么：** city 已参与文件系统路径拼接，这是真实路径穿越面，不是理论风险。

## 🔵 P2-6 `test_clear_thread_provider_falls_back` — 修测试而非改 clear

**文件：** `tests/test_llm_provider.py`  
（实现：`packages/curator/redtrip_curator/llm.py`）

**当前现状（本仓库实测）：**  
`clear_thread_provider()` 已正确 `_CLOUD_PROVIDER.set(None)`。无 env 时该测试 **已通过**。  
审计描述的失败会出现在 **环境变量已配置 `LLM_API_BASE`/`LLM_API_KEY`** 时：clear 只清 BYOK 覆盖，`llm_configured()` **故意**回落 env → 返回 True。这是产品语义，不是 clear 漏清。

**应该怎么改：**

```python
def test_clear_thread_provider_falls_back(monkeypatch):
    set_thread_provider({"api_base": "https://api.test/v1", "api_key": "sk-test"})
    clear_thread_provider()
    monkeypatch.delenv("LLM_API_BASE", raising=False)
    monkeypatch.delenv("LLM_API_KEY", raising=False)
    assert llm_configured() is False
    assert llm_model() == "Qwen-flash"
```

**不要改：** `clear_thread_provider` 去「连 env 一起关掉」——会破坏「无 BYOK 时用服务器默认模型」的主路径。

**为什么：** 测的是「线程覆盖已清除」，不是「机器上永远没有 LLM」。

## 🔴 P0-7 `test_points_has_exhibitions` — OSM buri 诚实约定

**文件：** `tests/test_p0_2_points.py`  
**数据：** `content/whitelist/points.json`

**当前现状（实测）：**  
`coord_source=="osm"` 共 150 点；其中 **1** 点有 buri：  
`张乐平故居` → `http://data.library.sh.cn/entity/architecture/xbfa2broqvrss7ce`（真 SLC URI，非伪造）。  
`assert all(buri is None)` 因此失败 → 全库 **1 failed / 74 passed**。

**应该怎么改（推荐）：** 保留诚实约定，允许「已真实映射」例外：

```python
osm_added = [p for p in pts if p.get("coord_source") == "osm"]
assert osm_added, "未发现 OSM 并入的文化场馆锚点"
for p in osm_added:
    buri = p.get("buri")
    if buri is None:
        continue
    # 允许：经 SLC 真实映射的 URI；禁止：任意非空占位 / 假串
    assert str(buri).startswith("http://data.library.sh.cn/"), (
        f"OSM 点 {p.get('name')!r} 的 buri 不是上图 URI: {buri!r}"
    )
```

**备选：** 把张乐平故居的 `coord_source` 改成非 `osm`（若坐标其实已校对）——改动数据语义更大，不优先。

**为什么：** 诚实约定防的是「无映射却填 buri」；真映射应保留并在测试里显式承认。
