## 它解决什么问题

红色研学、城市漫步不缺内容，缺的是**策展力**。

- **供给停在「点位串联」** —— 市面上的路线，本质是地图上的点一个个连起来，彼此孤立；你拿到的是清单，不是故事。
- **真人讲解难规模化** —— 资深策展人能讲出「一栋楼的多重人生」，但人工成本让好内容无法批量复制。
- **AI 不可信** —— 通用大模型张口就来年份、人物、事件，结论没有出处，错了你背锅。

红鸢把这件事变成**一句话触发**：你只要说出**和谁走、走多久、什么调性、从哪出发**，它就从上海图书馆的开放馆藏里取证、交叉印证，为你算出一条走得动、记得住的叙事漫步线——然后像策展人一样，把这条线装订成一本可以翻、可以走、可以带走的书。

一句话说清它和别家的区别：

> 别人在拼接点位，我们在**编织关系**——把散落在图书馆目录里的建筑、人物、事件，连成一条有主线、有转折、有收束的故事线。

## 一次策展长什么样

**1 · 出题** — 告诉它你的清晨、午后或黄昏：和谁一起，想走多久，喜欢什么调性，从哪一栋楼出发。

**2 · 策展** — 红鸢去图书馆的馆藏里取证、交叉验证、规划路线。几秒钟后，模板书页先翻给你看，润色一章完成一章——**不用干等**。

**3 · 序章** — 主题、人物、脉络先亮相：这一程为什么值得走，将遇见谁，讲一件什么事。

**4 · 章节阅读** — 每一站是一章：建筑的前世今生、一个人的多重人生、一条街的时代转身。翻页即读，像翻一本真正的书。

**5 · 舆图** — 海派配色的 2.5D 城市地图，路线与章节高亮对应，走着看、点着读。

**6 · 带走** — 一键导出 PDF / EPUB：把这一程装订成册，收藏，或分享给同路人。

## 为什么你可以信它

**每一句事实，都有出处。** 这是红鸢最硬的承诺，也是它和通用大模型最根本的区别：

- 策展只取材于**上海图书馆开放数据**的真实馆藏（建筑、人物、事件、地名、道路多路数据集），取证先于叙事；
- 正文里每一句史实都带**朱色上标**，点击即可展开原始馆藏记录，逐句可溯；
- 找不到依据的地方，红鸢**如实说"暂无数据支撑"**，绝不编造；未取证的年份、人名、事件会被硬性拦截，写不进去。

> 数字不可被幻觉辜负 —— AI 该算清楚，而不是侃侃而谈。

## 它凭什么不一样

| 维度 | 普通路线 App / 通用大模型 | 红鸢 RedTrip |
|---|---|---|
| 内容组织 | 点位串联，彼此孤立 | 跨库编织关系：一栋楼 × 一个人 × 一件时代大事 |
| 结论可信度 | 可能编造、无出处 | 每句事实锚定原始馆藏，逐句可溯源 |
| 可解释性 | 黑盒 | 句末上标即证据，点开看原记录 |
| 体验独特性 | 千站一面 | **红鸢抽签**：每次策展的读法、语气、延伸都不同，同一程走出不同味道 |
| 等待体验 | 生成完才能看 | **逐章流式**：模板先到、章节边生成边替换，第一章几十秒可读 |
| 成果形态 | 页面即看即忘 | 可导出 PDF / EPUB，装订成一本书 |

**红鸢抽签**：藏在策展背后的一只"词库纸鸢"。每一次出题，它都会抽一套读法——有的冷峻考据，有的温润抒情——但永远只在馆藏事实之内变换语气，绝不新增史实。同一座城市，可以走出很多种红鸢。
