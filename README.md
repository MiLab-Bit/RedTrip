## 品牌与产品能力

红色研学、城市漫步不缺内容，缺的是**策展力**。

- **供给停在「点位串联」**——市面上的路线，本质是地图上的点一个个连起来，彼此孤立；你拿到的是清单，不是故事。
- **真人讲解难规模化**——资深策展人能讲出「一栋楼的多重人生」，但人力成本让好内容无法批量复制。
- **AI 不可信**——通用大模型张口就来年份、人物、事件，结论没有出处，错了你背锅。

红鸢把这件事变成**一句话触发**。一句话说清它和别家的区别：

> 别人在拼接点位，我们在**编织关系**——把散落在图书馆目录里的建筑、人物、事件，连成一条有主线、有转折、有收束的故事线。

### 升级亮点

**1 · 证据分级 A–E，把「防幻觉」做成工程**

每一句史实都带置信度分级：**A 级**一手馆藏档案、**B 级**可靠策展词库、**C 级**通用二手资料、**D/E 级**传闻与推测。策展器先分级、再写作——料薄的地方它自己会收着说，绝不硬编。找不到依据，就**如实说「暂无数据支撑」**。数字不可被幻觉辜负。

**2 · 路线零件 · 长散文，每站 8000–10000 字**

每一站不再是一张干巴巴的卡片，而是一段**可以走的流动散文**：现场进入、时间叠层、人物、城市机制、行走者动作、转场——以**同行者口吻**娓娓道来。你走在路上，读的是一部城市小说；写它的不是导游，是和你并肩的那位朋友。

**3 · 反方策展人，每次策展后有人挑刺**

策展完成后，一位「专门唱反调的策展人」独立复核：**最可能错在哪、谁的声音被漏掉了、哪个更难处理的节点被跳过了**。挑刺成果收录进「策展留白」附录——好的策展，敢于把犹豫也摊开给你看。

**4 · 书籍化渲染器，一键成书**

同一份溯源叙事，可渲染成**网页 / MDX / EPUB / PDF**。策展的终点不是页面，是一本可以收藏、可以分享、可以随身带走的书。

## 技术与特色

| 层 | 选型 |
| --- | --- |
| 前端 | React 19 · Vite 8 · TypeScript 5.9 · Three.js + React Three Fiber（3D 城市场景） |
| 状态 | XState 5（策展流程状态机）+ Zustand 5 |
| 后端 | FastAPI（策展 API + 流式阅读 SSE） |
| 数据 | 上海图书馆开放数据（馆藏档案取证） |
| 测试 | Vitest 4 · 黄金测试回归 |

**工程特色**：

- **证据链是数据不是提示词**：A–E 分级随句流转，写作器按分级约束语气——防幻觉是工程机制，不是一句「请勿编造」
- **互搏式校验**：策展完成后独立「反方策展人」复核，挑刺成果进附录——把不确定性也变成产品内容
- **流式策展**：策展过程 SSE 实时可见，不是转圈等结果
- **一源多渲染**：同一份溯源叙事输出四种书籍格式，渲染器与策展器解耦
