## 它解决什么问题

红色研学、城市漫步不缺内容，缺的是**策展力**。

- **供给停在「点位串联」** —— 市面上的路线，本质是地图上的点一个个连起来，彼此孤立；你拿到的是清单，不是故事。
- **真人讲解难规模化** —— 资深策展人能讲出「一栋楼的多重人生」，但人力成本让好内容无法批量复制。
- **AI 不可信** —— 通用大模型张口就来年份、人物、事件，结论没有出处，错了你背锅。

红鸢把这件事变成**一句话触发**：你只要说出**和谁走、走多久、什么调性、从哪出发**，它就从上海图书馆的开放馆藏里取证、交叉印证、互搏式校验，为你算出一条走得动、记得住的叙事漫步线——然后像策展人一样，把这条线装订成一本可以翻、可以走、可以带走的书。

一句话说清它和别家的区别：

> 别人在拼接点位，我们在**编织关系**——把散落在图书馆目录里的建筑、人物、事件，连成一条有主线、有转折、有收束的故事线。

## 升级亮点（v2）

**1 · 证据分级 A–E，把「防幻觉」做成工程**

每一句史实都带置信度分级：**A 级**一手馆藏档案、**B 级**可靠策展词库、**C 级**通用二手资料、**D/E 级**传闻与推测。策展器先分级、再写作——料薄的地方它自己会收着说，绝不硬编。找不到依据，就**如实说「暂无数据支撑」**。数字不可被幻觉辜负。

**2 · 路线零件 · 长散文，每站 8000–10000 字**

每一站不再是一张干巴巴的卡片，而是一段**可以走的流动散文**：现场进入、时间叠层、人物、城市机制、行走者动作、转场——以**同行者口吻**娓娓道来。你走在路上，读的是一部城市小说；写它的不是导游，是和你并肩的那位朋友。

**3 · 反方策展人，每次策展后有人挑刺**

策展完成后，一位「专门唱反调的策展人」独立复核：**最可能错在哪、谁的声音被漏掉了、哪个更难处理的节点被跳过了**。挑刺成果收录进「策展留白」附录——好的策展，敢于把犹豫也摊开给你看。

**4 · 书籍化渲染器，一键成书**

同一份溯源叙事，可渲染成**网页 / MDX / EPUB / PDF**。策展的终点不是页面，是一本可以收藏、可以分享、可以随身带走的书。

**5 · 逐章流式，不用干等**

模板书页先翻给你看，章节边生成边替换——第一章几十秒即可读，长散文在后台从容生长。

**6 · 红鸢抽签，每次读法不同**

藏在策展背后的一只「词库纸鸢」。每一次出题，它都会抽一套读法：有的冷峻考据，有的温润抒情——但永远只在馆藏事实之内变换语气，**绝不新增史实**。同一座城市，可以走出很多种红鸢。

## 一次策展长什么样

**1 · 出题** — 告诉它你的清晨、午后或黄昏：和谁一起，想走多久，喜欢什么调性，从哪一栋楼出发。

**2 · 策展** — 红鸢去图书馆的馆藏里取证、交叉验证、规划路线。模板书页先到，章节边生成边替换——**不用干等**。

**3 · 序章** — 主题、人物、脉络先亮相：这一程为什么值得走，将遇见谁，讲一件什么事。

**4 · 章节阅读** — 每一站是一章：建筑的前世今生、一个人的多重人生、一条街的时代转身，附上 8000–10000 字的路线零件长散文。翻页即读，像翻一本真正的书。

**5 · 反方策展** — 独立评审上场挑刺：最可能错在哪、谁的声音缺失、哪个更难的节点被跳过，如实写进「策展留白」附录。

**6 · 舆图** — 海派配色的 2.5D 城市地图，路线与章节高亮对应，走着看、点着读。

**7 · 带走** — 一键导出 PDF / EPUB / MDX：把这一程装订成册，收藏，或分享给同路人。

## 开发者入口

**技术栈**：pnpm monorepo · 后端 FastAPI + Python · 前端 React 19 + TypeScript + Vite + Zustand + XState · 内容管线 RAG 接入 OSM / 高德 / 上海图书馆等多路数据源。

**数据源口径**：已接通 live 2 家（上海图书馆 + 搜韵）；其余机构仅完成注册，待授权数据落盘后才会标记 ready。`/v1/providers?probe=true` 可查看本次真实探测结果。

**内容管线（唯一真身）**：

```
intent → evidence（证据分级 A–E）→ plan → narrative → polish（长散文）→ gate → review（反方策展人，非阻断）
```

**仓库结构**：

| 包 | 路径 | 职责 |
|---|---|---|
| `apps/api` | `apps/api/app/main.py` | FastAPI 入口：`/v1/curate` `/v1/cities` `/v1/providers` `/v1/book*` `/v1/auth*` `/v1/model-providers` |
| `apps/web` | `apps/web/src` | 前端：出题页 + 城市选择 + 逐章流式阅读 + 2.5D 舆图 |
| `packages/curator` | `redtrip_curator/` | 核心内容管线（intent/evidence/plan/narrative/polish/review/book） |
| `packages/gate` | `redtrip_gate/` | 套话拦截 + 门禁阈值 + essay 同行者口吻白名单 |
| `packages/library-client` | `redtrip_library/` | 数据源注册表（**已接通 live 2 家：上图 + 搜韵**，其余注册待授权）+ 端点封装 |
| `packages/contracts` | `src/index.ts` | 前后端契约（前端直读源码免构建） |
| `packages/tools` | `build_osm_pois.py` | 免 key 拉取 OSM POI（多城市） |

**快速开始**：

```bash
# 1. 环境：复制 .env.example 为 .env，填入 SLC_API_KEY（上图开放数据）与 LLM_API_*（OpenAI 兼容网关）
# 2. 后端（apps/api）：
python -m venv .venv && .venv/bin/pip install -r apps/api/requirements.txt
.venv/bin/python -m uvicorn app.main:app --port 8799   # 工作目录 apps/api

# 3. 前端（apps/web）：
pnpm install && pnpm --filter '@redtrip/contracts' build
pnpm --filter '@redtrip/web' dev

# 4. 竞赛演示（推荐）：打开前端后点「演示武康 · 六站可溯源」
#    或 curl http://127.0.0.1:8799/v1/demo/wukang
#    脚本见 Doc/15-demo-script.md

# 5. 测试与静态检查：
.venv/bin/python -m pytest tests -q
.venv/bin/python -m redtrip_gate.redteam.runner
python eval/smoke_demo.py
.venv/bin/python -m ruff check packages/
```

**竞赛演示入口**：前端 Brief 页 **「演示武康 · 六站可溯源」** / **「演示一大·外滩 · 通道诚实」** → `GET /v1/demo/wukang` / `GET /v1/demo/yida`（冻结包，非失败兜底）。真实策展仍走 `/v1/curate`。

**eval 基线**：`python eval/baseline.py`（buri 覆盖率 + 两条演示线 Gate/套话/溯源）；`python eval/smoke_demo.py`（CI 烟测）。

**演示叙事加厚**：`python scripts/enrich_demo_narratives.py`（把冻结包 story_card 补到策展级密度，并重建句级溯源）。

**配置**：所有密钥走环境变量（见 `.env.example`），**不落盘、不入 git**；用户可自带大模型密钥（BYOK），服务端加密存储、仅本人可见。

## 品牌故事

**红鸢** —— 以「红鸢」为名，牵引城市深处的记忆之线。从图书馆的旧藏、街巷的建筑，到被时间收藏的名字与诗句，红鸢将散落的城市故事重新连接，化作一场可以行走的展览。

**RedTrip** —— 「红」为红色文化，「鸢」是纸鸢，也是上海弄堂里最常见的那抹天空。我们以「红鸢」替你牵起一张城市记忆的线：把散落在图书馆目录里的名字、建筑、年代与诗句，连成一场你走得动、记得住的展览。
