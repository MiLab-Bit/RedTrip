## 0. Verdict

> ## **有条件 GO**
> **一句话理由**：需求侧与供给缺口已证实（三馆 410 万年到访 vs 上历博千人量级 = 0.02% 覆盖）；沪小游虽已具备生成能力，但其 16 个月可观测行为**全部投入广度而非深度**（真实增速放缓、能力清单零新增），深度差比"纯窗口期"判断更可守——但仍有两件事未验证，故有条件放行。

**放行条件（两条，锁方案前必须有答案）**
1. **B 端付款人可指名**：拿到 1 条写得出"谁签字 / 走哪笔预算 / 单价与批量"的具体采购路径。拿不到，"B 端为主"仍是假设，全案应降级为竞赛作品定位。
2. **S0-4 长尾非空率 ≥60% 且真实可达层数 ≥3**（数析已把此实验升级为全案第一优先）：低于门槛则"策展深度"只存在于几栋名楼、而那几栋沪小游 6.2 万条目里也有 → **我方不存在任何可辩护差异化**，自动触发降级为竞赛作品定位。

## 1. 主威胁沪小游：**不是能力壁垒，是动机差异——且真威胁已转移**

### 1.1 真实增速读数（同一指标、两个时点，回应数析监测项）

数析判断：沪小游的增速是判断窗口期"还剩几个季度"的唯一可靠依据。已取到**同指标双时点读数**（同一记者、同一通讯社）：

| 时点 | 读数 | 口径 | 信源 |
|---|---|---|---|
| 2025-12-31 | **约 1300 万人次** | 累计服务用户 | 新华社（陈爱平） |
| 2026-07-20 | **近 2000 万人次** | 累计服务来沪游客 | 新华社（陈爱平） |

- 上线（2025-03）→ 2025-12：约 9.7 个月 ≈ **134 万/月**
- 2026-01 → 2026-07：约 6.7 个月 ≈ **104 万/月**
- **近期增速较初期放缓约 22%，未出现加速** → 数析最担心的"若为同一指标且加速（250 万/月 ≈ 3000 万/年）"假说**被读数否定**。
- 按近期增速年化 ≈ **1100–1250 万/年**（比全期平均年化的 1400–1500 万更保守，建议对外用此区间或直接给"约 1200 万/年"）。
- ⚠️ 计数口径有微差（"服务用户" vs "来沪游客"），绝对增速请数析终核；但"放缓、非加速"的**方向性结论对三种解读均稳健**。
- 附带发现：资源条目 2025-12 为 **4.5 万** → 2026-05 为 **6.2 万**（5 个月 +38%，年化近 90%）——**条目增速远快于用户增速**。

### 1.2 结构性判断：它的 KPI 让它没有动机做深度

沪小游上线 16 个月，能力清单（AI 定制行程 / AIGC 游记 / 资源推荐 / 智能购票）**零新增**；全部增量投向了广度（条目 +38%、类目 33→36 大类 107 小类、语言 10+ 种）。它作为"一站式总入口"的 KPI 是覆盖与服务人次——策展深度对它是**负成本**（人工审核、红色题材风险、不涨 KPI）。
→ 此前"窗口以季度计"的**悲观读数可上修**：沪小游自身深度升级的动机弱，深度差的可守期更长。**这是动机约束，不是能力壁垒，评审中仍禁止称"壁垒"。**

### 1.3 ⚠️ 真威胁转移：不是沪小游升级，是"官方先锋产品名额"的第三方

上海市文旅局已公开计划（新华社 2025-12-31）：未来三年产出 **5+ 文旅开放语料库、10+ 垂类模型、20 个文旅 AI 先锋产品、30 个 AI 示范场景**。深度型产品大概率由**第三方供应商**开发后**接入沪小游生态**——真正的威胁不是沪小游自己补深度，而是**另一个供应商抢走"先锋产品/示范场景"的官方名额**。
→ 这同时是**机会窗口 C（官方编制）**：接入优于对抗从"抽象策略"变成"具体坑位"。GTM 新增目标：直接瞄准 20 先锋产品 / 30 示范场景名额，让"上图数据竞赛获奖"成为申报先锋产品的入场券。

### 1.4 三支点重估（维持 v1 结论）

①引擎 vs 线路 = **守不住**（禁称壁垒，改讲"深度分层"）；②可溯源合规 = **半守**（是它的动机约束、非我方能力壁垒，对 B 端算信任凭证）；③**B 端策展引擎 = 唯一真守得住**（它是 C 端流量入口，无动机做馆方内容生产工具）。

## 2. 上历博：判为**首选 B 端客户**成立，但不是"数字化洼地"

免费但稀缺（千人量级/年、15 人上限、需抢名额）→ 不构成价格锚，扩容痛点真实，此判维持。
⚠️ 补充：其具身导览机器人「历小博」已服务数万人次并**入驻文创商店**——说明馆方数字化预算与意愿都在，且**已有现成轻履约通道**（对我方 30–100 元轻履约实验是利好参照，但也意味着它有自建能力）。BD 话术须从"帮你数字化"改为"帮你把一条线变成 N 条线"。

## 3. 我方差异化的真实成色（v2：rubric 拆双轴）

**A 轴 = 叙事深度**（只衡量内容本身；已把"生成物"移出，见数析附录 §2）：

| 级 | 定义 | 一句话判别 |
|---|---|---|
| A1 | 播报/问答：回答"这是什么" | — |
| A2 | 索引/打卡/行程：罗列点位，只给"顺路/距离/时间"关系 | "为什么选这些点？→ 因为顺路" |
| A3 | 单馆深讲：一个点位讲透 | "为什么是这个顺序？→ 因为这是它的故事" |
| A4 | 跨点策展：点位间有**史实线索**串联成叙事 | "为什么这些点？→ 因为一条历史线索" |
| A5 | **跨库史料缝合 + 逐句可溯源**：A4 + 关系来自多数据集交叉 + 每句可回溯到 URI | "为什么这些点？→ 因为跨库史实交叉，且每句可查" |

**B 轴 = 交付形态**（只衡量产物，与深度正交，**非壁垒、两周可追平**）：

| 级 | 定义 | 玩家 |
|---|---|---|
| B0 | 无产物 | 上历博（线下带队） |
| B1 | 文本产物（行程单/游记） | 沪小游（AI 游记） |
| B2 | 结构化素材包（地图/故事卡/今昔同框/机位卡） | 我方（目标） |

**读表（诚实版，全员口径）**：
- 沪小游 = **A2 / B1**（行程 + 游记，广度优先，A 轴 16 个月未动）。
- 上历博 = **A4 / B0**（有叙事线索，但单馆数据 + 无逐句溯源 + 无线下产物）。⚠️ 新版 rubric 下**它与我们不再是"同 5 级平手"**，而是差一级（A4 vs A5）——但**这一级只在我们 S0-4 实测证明 A5 成立后才算数**；S0 前对外仍按"同属策展级、差异在产能"表述，禁写"我们深度更高"，避免自证。
- 我方目标 = **A5 / B2**，两要件均可现场验收（跨库 join 层数 + 逐句 source）。
- **对外一句话（已由数析提出，建议直接进演示话术）**：*"它有 6.2 万条目录条目，我们做的是条目之间的关系——目录再多也生成不出'一栋楼的多重人生'。"* 抗反驳强度高于任何"我们更深"的表述。
- **战术纪律**：B 轴（结构化素材包）任何人两周可追平，**禁止当差异点讲**；差异点只在 A5，而 A5 的命门是 S0-4。

## 4. 市场风险与机会窗口

| | 内容 |
|---|---|
| **最大风险** | 不再是"沪小游升级深度"（其行为数据表明动机弱、增速放缓），而是 **S0-4 证明 A5 不成立**（长尾非空率 <60%）→ 深度差异化崩塌，全案降级为竞赛作品；或 **官方先锋产品名额被第三方抢走** |
| **次风险** | B 端决策链外置（预算在宣传口/组织口、红途已在位）→ 我方大概率是"生态内供应商"而非独立卖方；零政采资质与案例 |
| **机会窗口 A（竞赛）** | 上图开放数据竞赛 = 低成本拿官方背书与案例的唯一近场通道，且是申报"20 先锋产品"的入场券 → 优先级应高于任何 C 端动作 |
| **机会窗口 B（背书）** | 沪小游生态"深度协同第三方平台"是既成模式 → **接入优于对抗**：以内容供给层身份进入 |
| **机会窗口 C（官方编制）** | 上海已公示三年计划：**20 个文旅 AI 先锋产品 + 30 个示范场景** → GTM 直接瞄准这些官方坑位，把"竞赛获奖 → 先锋产品名额 → 与沪小游生态对接"串成申报路径 |

## 5. 一句话定位建议

> **不做第二个沪小游，做沪小游与场馆背后的"策展深度供给层"——别人给一条线路和一份游记，我们给场馆一台按需产出策展级线路的引擎。**
