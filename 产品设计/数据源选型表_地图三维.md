> 标注说明：**✅ 适合 / ⚠️ 需确认 / ❌ 不适合或不可得**。
> ⚠️ 表示公开信息不足以下定论，比赛若商用上线前须向官方复核授权。

## 二、推荐组合（采纳你的 4 点配法）

| 层 | 选型 | 职责 |
|----|------|------|
| 底图 | 天地图·上海 | 稳定地图服务、POI、路径 |
| 空间感 | 实景三维上海 / 意象框架城市（参照） | 2.5D 城市骨架的视觉目标 |
| 文化叙事层 | 上海图书馆开放数据 MCP（slc_red_event / slc_building / slc_era …） | 内容主题与真实史实 |
| 美学渲染层 | 自研（老上海色调 + 海派字体 + 卡片式场景） | 统一视觉表达 |

> 结论：不自建测绘级三维，而是**天地图做底 + 自研意象化 2.5D 骨架 + 图书馆 MCP 做内容**，既可控又避开商用授权雷区。

## 三、在项目里的接入架构

```
[用户模糊意图]
      │
      ▼
[Agent 编排层]  ←── 总 Prompt v2（意图判读 / 工具取证 / 策展）
      │
      ├── 文化叙事层：上海图书馆 MCP
      │     slc_red_event / slc_building / slc_era / souyun_poem …
      │
      └── 空间底座层
            ├── 天地图 MCP（自封装）：POI / 路径 / 瓦片
            └── 2.5D 渲染层（前端）：意象化骨架 + 美学样式
                                     ↑ 风格参照"实景三维意象框架城市"
```

- **MCP 包装建议**：天地图无现成 MCP，需自写 stdio server（持 Key 调 REST），复用你已接的 `slc_mcp_server.py` 同款模式。
- **虚拟上海 GIS**：若取得到 GeoJSON，封装为"历史边界/专题查询"工具，作为 `slc_building` 的文化叠层补充。
