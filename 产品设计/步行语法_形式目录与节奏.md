# 《步行语法》形式目录 · 节奏 · 隐形场景表

> **双轨**：① 每章换一种叙事方法（形式创新）；② 全书只讲**一个**故事，主角**吟游诗人**。  
> 目录只写方法名，不写场景；上海靠视觉与正文肌理证成。

---

## 0. 故事脊骨（制作侧 · 可透露给作者，勿印进目录）

**一句话**：会唱的人突然唱不出完整的歌；城市把她当作未完成的歌词，逼她走完才肯把句子还给她。

| 节拍 | 故事功能 | 落在哪些章 |
|---|---|---|
| 钩子 | 吟游诗人失歌；只剩一句残句与一张无字地图 | 凡例 → 剧本分镜 |
| 立约 | 她答应「用十五种说法走完」，每走一种，收回一截旋律 | 意识流 · 多视角拼贴 |
| 加深 | 人称与距离变化：被命令、被六词切割、被「我们」吞没、收到旧信 | 第二人称 → 书信体 |
| 逆转 | 时间与格律反噬：倒着走、十四行锁死、维拉内拉回旋 | 倒叙 → 维拉内拉 |
| 代价 | 颂与挽同时成立——歌能回来，但有人/有处回不来 | 颂歌与挽歌 |
| 证物 | 清单与反讽让她看清：歌不是风景，是条目与错位 | 清单体 · 戏剧反讽 |
| 收束 | 章册可撕走；读者与她各自带走未完成的一公里 | 章册 |

硬规则：形式服务于故事节点；故事不得为凑形式而注水；无上图依据的事实句不写。

## 3. 质量标准

- **故事**：每章推进至少一件事（获得/失去/误认/偿还）；禁止空转形式表演。  
- **形式**：章与章方法不重复；章内方法纯度 ≥80%。  
- **趣味**：易懂区先爽；约束区变难但不晦涩到丢主角。  
- **证据**：可核查句标注来源或「未收录」。  
- **字数**：短形式用「组/连作」凑配额，不注水对话。
