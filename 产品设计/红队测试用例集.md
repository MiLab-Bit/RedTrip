# 红队测试用例集（Red-Team Test Suite）

> 配套：`研学SOP与交付质量保障体系.md` 的"生成后·红队回归"
> 目标：把质检从文档落成可执行回归——每条用例 = 输入 query + 期望契约 + 断言；CI 跑一遍即知是否发生编造 / 越界 / 残缺。

---

## 一、维度矩阵

| 轴 | 取值 |
|---|---|
| persona | 亲子 / 教师 / 成人 |
| 主题 | 红史(`slc_red_event`) / 建筑(`slc_building`) / 诗词(`souyun_poem`) / 综合(跨工具) |
| 边界 | 含糊输入 / 工具不可达 / 跨时代(`slc_era`) |

## 四、自动化断言规范（对应 KPI）

| 编号 | 断言 | 对应 KPI | 失败即 |
|---|---|---|---|
| A1 | 契约完整：`intent/theme/logic_line/aesthetic/scenario/why_visit/sources/blocks` 全非空 | 契约完整度 ≥98% | 拦截 |
| A2 | 来源可溯：递归所有 `source` 字段非空且为 `http(s)` 链接 | 数据可溯率 100% | 拦截 |
| A3 | 零编造：事实类字段（`fact/event/figure/address/era`）须带 `source` | 编造率 0 | 拦截 |
| A4 | palette 合规：所有 `color` 字段 ∈ 6 色 + 宣纸底 | 美学违规 0 | 拦截 |
| A5 | 5 要素齐：`theme/logic_line/aesthetic/scenario/why_visit` 全有值 | 意图满足度 | 拦截 |
| A6 | 槽位显式：输出含 `persona` 字段（声明或补全） | 一致体验 | 警告 |
