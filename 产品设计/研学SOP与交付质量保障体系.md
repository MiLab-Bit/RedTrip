# 研学 SOP 与交付质量保障体系

> 适用对象：基于「上海图书馆开放数据 MCP」的文化策展型 Agent（红色上海 / 城市记忆 / 研学体验）
> 目标：把"质量"从事后抽查，内建为"生成前—生成中—生成后"三阶段强制门禁

---

## 一、第一性原理（为什么这么设）

质量不是验出来的，是设计出来的（Deming）。本类 Agent 有四类等价失效模式，须针对性设防：

1. **编造（hallucination）**——事实无数据源头。
2. **风格漂移**——一会儿学术口吻、一会儿营销口吻。
3. **美学越界**——超出海派 palette、伪造精确高度/年代。
4. **可用缺口**——产出无法渲染、无法传播、无"人想去看"的理由。

结论：质控必须前置并固化进 SOP，而非依赖人工审稿兜底。

---

## 二、生成前：输入治理（SOP 入口）

| 动作 | 规则 | 作用 |
|---|---|---|
| 意图路由 | 路线 / 手册 / 卡片 / 场景页 / 策略 → 锁定对应输出契约 | 防止契约错配 |
| 5 槽位补全 | 人群·场景·时长·风格·交付形；缺 ≥3 才问 1 问，否则按默认 persona（成人·半天·城市记忆·轻松版）假设并显式声明 | 防无效澄清、保一致 |
| 工具健康检 | 调用前确认目标 MCP 工具可达；不可达则降级声明"暂无数据支撑" | 防运行时崩、防编造 |

---

## 三、生成中：过程硬约束（写进 system prompt）

- **取证铁律**：事实须来自工具返回；多源须组合调用示范；标注 `source`；无据明说"暂无支撑"不补编。
- **结构化契约强制**：先输出 JSON 信封（`intent / theme / logic_line / aesthetic / scenario / why_visit / sources / blocks`），字段缺失即拦截，再生成可读文案。
- **美学护栏**：6 色海派 palette 锁死（墨/赭石/青灰/米白/朱/宣纸）；不造建筑；来源角标；示意高度诚实标注。
- **自校验**：输出前过 5 要素（主题 / 逻辑线 / 美学基调 / 可用场景 / 人会想去的理由），缺哪个补哪个。

---

## 四、生成后：交付质检（门禁）

**自动层（脚本化）**
- JSON Schema 校验 → 契约完整度
- 来源可达性扫描 → 链接返回 200
- palette 合规扫描 → 色值越界即违规
- 槽位完整度检查 → 5 槽位是否齐备或已声明

**人工层（策展复核）**
- 文化准确性：不脸谱化、不口号化、不"抗日神剧化"
- 叙事分寸：克制、有温度、有画面感
- 红队回归：每版跑固定用例集（亲子 / 教师 / 成人 × 红史 / 建筑 / 诗词）

---

## 五、定量 KPI（门禁阈值）

| 指标 | 目标 | 测法 |
|---|---|---|
| 数据可溯率 | 100% | 事实字段 `source` 非空 |
| 编造率 | 0 | 红队抽检 + 来源反查 |
| 美学违规 | 0 | palette 扫描 |
| 契约完整度 | ≥ 98% | schema 校验 |
| 意图满足度 | ≥ 4/5 | 人工双评 |

---

## 六、Definition of Done（单条交付出门条件）

- [ ] 结构化 JSON 通过 schema 校验
- [ ] 所有事实字段带可达 `source`
- [ ] palette 扫描无越界
- [ ] 5 要素齐全
- [ ] 含 ≥1 个"人会真的想去看 / 想去用"的理由
- [ ] 通过对应 persona 的红队用例

---

## 七、比赛交付附加项

- **Demo 稳定性**：MCP 挂掉有离线兜底文案，不崩。
- **可复现**：固定默认 persona / seed，评委重跑结果一致。
- **文档三件套**：总 Prompt v2 + 数据源选型表 + 本体系，齐备可查。
